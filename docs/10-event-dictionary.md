# 10. AMI 이벤트 사전 (자동 생성)

> `make event-dict`로 다시 만든다. 손으로 고치지 않는다. 원본: 녹화 13개 (`engine/testdata/` sim-normal-and-abandon.log, sip-agent-call.log · `engine/state/testdata/` abandon.ami, attended-transfer.ami, blind-transfer.ami, caller-hangup.ami, hold.ami, noanswer.ami, normal.ami, queue-timeout.ami, ring-abandon.ami, sip-agent.ami, three-way.ami), 이벤트 1578개.
> 이 환경(Asterisk 22.11)에서 실제로 본 이벤트와 필드만 있다. 녹화에 없는 이벤트는 `make rx c="manager show event 이름"`으로 본다.
>
> **{채널}** = 채널 스냅샷 필드 14개 (`Channel` `ChannelState` `ChannelStateDesc` `CallerIDNum` `CallerIDName`
